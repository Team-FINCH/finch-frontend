# Finch Design Guide

> **복잡한 투자 정보는 명확하게, 어려운 투자 판단은 친절하게.**

Finch는 주식에 투자하는 사람을 위한 AI 투자 어시스턴트다.
펀드에 매니저가 있듯 주식에는 Finch가 있다 — 쏟아지는 공시와 뉴스에서 내 종목에 필요한 것만 골라내고, 계좌 전체의 흐름까지 함께 정리한다.

일반적인 증권 앱에 가까운 신뢰감을 유지하되, 판단이 필요한 순간에만 AI가 근거를 정리해 준다.

- 최종 수정: 2026.09.04
- 기준: 최신 모바일 프로토타입 + 기능/API 명세 반영
- v2.2 — §7.16 온보딩(관심 종목 선택) 추가
- v2.1 — 이슈 #32 확정값 5건 반영 (AI Surface 토큰 · AI Accent · 좌우 여백 · Radius · 근거 표기)

## 1. Design Concept

### Core Concept

**White & Graphite 기반의 차분한 증권 앱 + 검정 Surface로 구분되는 AI 영역**

- 전체 UI는 **화이트·그래파이트·쿨그레이** 중심으로 차분하고 전문적으로 구성
- AI가 관여하는 영역은 **검정 Surface 또는 공통 AI Glyph**로 일반 금융 정보와 구분
- 투자 정보를 과도하게 장식하지 않고 **숫자·타이포그래피·정보 위계 중심으로 구성**
- TDS의 명확한 정보 위계와 여백 설계를 참고하되, **과도한 카드·Pill·대시보드형 그래픽은 사용하지 않는다**
- 정보량이 많아도 한 번에 하나의 핵심이 읽히도록 **Typography / Spacing / Alignment** 중심으로 구성

### Design Keywords

- **Trustworthy** — 금융 서비스다운 신뢰감
- **Clear** — 복잡한 정보를 쉽게 읽을 수 있는 명확한 위계
- **Calm** — 과도하게 자극적이지 않은 차분한 화면
- **Friendly** — 어려운 투자 정보를 부담 없이 이해할 수 있는 친절함
- **Personal** — 내 종목·내 포트폴리오·내 투자 기준 중심의 개인화 경험

## 2. Target UX

### Main Target

**주식에 투자하는 사람.** 연령으로 좁히지 않는다.

초보자에게는 초보자에게 필요한 조력자가, 어느 정도 하는 사람에게는 그에 맞는 조력자가 된다.
정보를 스스로 찾아 읽을 시간이 부족하다는 점이 공통 조건이다.

### UX Principles

1. 한 화면에서 가장 중요한 정보가 바로 보이도록 구성
2. 금융 용어는 그대로 쓰고, 필요한 경우 쉬운 해석을 덧붙인다
3. 매수·매도 등 중요한 행동은 크고 명확한 버튼 사용
4. AI가 판단을 대신하지 않고 **근거·위험·확인할 점**을 함께 제시
5. 뉴스·기업 정보·포트폴리오·투자 기록을 연결해 사용자가 직접 판단하도록 지원
6. 사용자를 재촉하지 않는다. 기록·확인이 필요한 일은 알림함에 쌓아 둔다
7. 같은 의미를 색·아이콘·배지·문구로 중복 강조하지 않는다
8. 중요한 정보는 카드보다 **배치 순서와 타이포그래피**로 먼저 강조한다

## 3. Brand Mark & AI Glyph

### Brand Positioning

**Finch = 사용자의 투자 판단을 돕는 AI 어시스턴트**

브랜드는 새(Finch) 모티프를 사용하지만, 제품 UI에서는 귀여운 캐릭터보다 **차분한 마크와 AI Glyph**로 표현한다.

### Brand Mark

브랜드 마크는 **새 실루엣**을 기본으로 한다.

**사용 영역**

- 랜딩 / 온보딩
- 브랜드 소개
- 마케팅 콘텐츠

**제품 UI에서 제한**

- 현재가 / 등락률 / 차트
- 총자산 / 평가손익
- 매수·매도 버튼
- 거래 내역
- 종목 리스트

### AI Glyph

제품 UI에서 AI가 관여한 정보를 표시할 때는 **공통 AI Glyph 하나로 통일**한다.

권장 형태:

- Dark Rounded Square
- White Finch Symbol 또는 단순화된 Finch AI Symbol
- 작은 크기에서도 형태가 무너지지 않는 단순 실루엣
- 필요 시 Sparkle을 한 번만 사용

**사용 영역**

- AI Summary Header
- AI Inline Insight
- AI 진입점
- 탭바 AI 버튼

**Scale**

- AI Inline / Header: **28~36px**
- 탭바 AI 버튼 내부: **20~24px**
- 랜딩 일러스트: **112~132px**

### AI Glyph Rules

- 화면마다 `✦`, 새 실루엣, 다른 AI 아이콘을 임의로 혼용하지 않는다
- 한 화면에서 AI Glyph를 과도하게 반복하지 않는다
- Gradient / 3D / Shadow 금지
- 제품 UI에서는 복잡한 새+노트북 일러스트를 그대로 축소하지 않는다
- 소품·표정이 있는 상세 캐릭터 버전은 마케팅/온보딩 용도로 제한
- 검정 Surface 위에서는 White Symbol 사용

## 4. Color System

전체 방향은 **White & Graphite**로 확정한다.
AI 영역은 웜톤이 아니라 **Dark Charcoal / Graphite Surface**로 구분한다.

### Representative Colors

| Role           | Token          | Color     | Usage                                |
| -------------- | -------------- | --------- | ------------------------------------ |
| **Primary**    | `--t1`         | `#1F2328` | 주요 텍스트, 핵심 버튼               |
| **AI Surface** | `--ai-surface` | `#24272C` | AI 카드 배경 (`--t1`보다 반 톤 밝다) |
| **Background** | `--bg`         | `#F7F8FA` | 전체 화면 배경                       |
| **Surface**    | `--surface`    | `#FFFFFF` | 기본 카드, 바텀시트                  |
| **AI Accent**  | `--ai-accent`  | `#E9C77F` | 검정 Surface 위 핵심 숫자·상태 강조  |
| **Notify**     | `--notify`     | `#D94A4A` | 알림함 미확인 점/뱃지 등 알림 상태   |

> **AI Surface는 `--t1`이 아니다.** `--t1`(#1F2328)은 텍스트·주요 버튼용이고, AI 카드는 `--ai-surface`(#24272C)를 쓴다.
> 과거 토큰에 있던 `--ai: #F4F6F8`은 AI와 무관한 안내 카드 배경이었다. `--note` / `--note-b`로 이름을 바꿨으니 AI Surface로 오해하지 않는다.

### Supporting Neutrals

| Token          | Color     | Usage                    |
| -------------- | --------- | ------------------------ |
| `--t2`         | `#565C66` | 보조 텍스트              |
| `--t3`         | `#78828E` | 캡션, 기준 시각, 출처    |
| `--border`     | `#E9ECEF` | 카드·구분선              |
| `--border2`    | `#D9DEE5` | 입력 필드, 강한 구분     |
| `--brand-soft` | `#F0F1F3` | 선택 상태, 얕은 Surface  |
| `--note`       | `#F4F6F8` | 안내 카드 배경 (AI 아님) |
| `--note-b`     | `#E1E6EB` | 안내 카드 테두리         |

### Semantic Stock Colors

| Token    | Color     | Usage              |
| -------- | --------- | ------------------ |
| `--up`   | `#C93B3B` | 상승 / 매수 텍스트 |
| `--down` | `#2258C9` | 하락 / 매도 텍스트 |
| `--neu`  | `#6B7280` | 보합               |

상승 빨강 / 하락 파랑. 서구권과 반대다.

매수·매도 버튼의 테두리·`:active` 배경은 위 값에서 파생한다. 구 팔레트(`#E25555` · `#3B82F6`) 하드코딩을 남기지 않는다.

| 위치             | 값                    |
| ---------------- | --------------------- |
| 테두리 · 매수    | `rgba(201,59,59,.4)`  |
| 테두리 · 매도    | `rgba(34,88,201,.35)` |
| `:active` · 매수 | `rgba(201,59,59,.08)` |
| `:active` · 매도 | `rgba(34,88,201,.08)` |

### Color Usage Rule

- 화면의 대부분은 **White / Graphite / Gray**
- AI Summary Surface는 **Dark + White**
- Dark Surface 안에서만 AI Accent를 제한적으로 사용
- AI Accent는 한 카드 안에서 최대 2~3곳만 사용
- AI Accent `#E9C77F`는 **검정 Surface(#24272C) 대비를 기준으로 정한 값**이다. 밝은 배경 기준값(`#E3B341`)을 쓰지 않는다
- 검정 카드 안의 버튼·구분선은 흰색 계열(테두리 22% · 글씨 82%)을 쓴다. `--t2` 같은 진한 회색은 검정 위에서 읽히지 않는다
- 상승·하락 색상은 금융 의미 전달에만 사용하고 **장식용·상태용으로 쓰지 않는다**
- 미확인 알림 점·뱃지는 `--notify`를 쓴다. `--up`을 쓰지 않는다
- `맞아요 / 아니에요`, `도움됐어요 / 아쉬워요`는 Green / Red로 구분하지 않는다
- 종목 로고 배경색은 **옅은 배경 + 톤 낮춘 글자색**으로 제한

> **White / Graphite = 금융 정보**
> **Dark Surface = AI 정상 결과**
> **AI Accent = 검정 위 핵심 하나**
> **Red / Blue = 금융 의미**
> **Notify Red = 미확인 상태**

## 5. Typography

### Font

- Korean: `Pretendard Variable`, `Pretendard`
- Fallback: `system-ui`, `-apple-system`, `sans-serif`
- 숫자: `font-variant-numeric: tabular-nums` 전역 적용

### Type Scale

| Type    |    Size |  Weight | Usage           |
| ------- | ------: | ------: | --------------- |
| Display | 36~40px |     700 | 현재가, 총자산  |
| H1      | 26~28px |     700 | 화면 제목       |
| H2      | 19~22px |     700 | 섹션 제목       |
| H3      | 17~18px |     600 | 카드 제목       |
| Body    | 15~16px | 400~500 | 일반 내용       |
| Small   |    14px | 400~500 | 보조 정보       |
| Caption | 12~13px |     400 | 기준 시각, 출처 |

### Rules

- 본문 기본 크기 **15px 이하로 낮추지 않는다**
- 중요 수치는 텍스트보다 크고 굵게 표시
- 동일 카드에서 굵은 글씨를 과도하게 사용하지 않는다
- 금액에는 천 단위 구분자
- 단위(`원`)는 숫자보다 한 단계 작고 낮은 명도
- 한 문장에 하나의 정보
- 모바일에서 2줄을 넘는 핵심 문장은 다시 줄인다

## 6. Layout

### Mobile First

- 기준 화면: **390~430px**
- 좌우 기본 여백: **26px** (전 화면 통일)
- 같은 Section 내부 간격: **8~20px**
- Section 간 간격: **28~44px**
- 최소 터치 영역: **44×44px**

### Card / Surface

- Radius: **12px** (`--radius-card`) — 카드·AI Surface·정보 묶음 전부 동일
- 예외: 버튼 **14px** · 칩 **11px** · 바텀시트 상단 **24px** · 종목 썸네일 **14px**
- 모든 요소를 큰 라운드 카드로 감싸지 않는다
- 필요한 영역만 Surface로 묶고 단순 정보는 **여백과 Divider**로 구분
- Shadow 최소화
- 한 카드에는 하나의 핵심 목적만 배치
- Light Surface는 "그룹핑"이 필요한 정보에만 사용
- Pill은 상태/필터 등 명확한 이유가 있을 때만 사용

### Tab Bar

앱의 하단 골격. **AI 진입점은 플로팅이 아니라 탭바 안에 있다.**

- 높이 **98px 고정.** 화면·상태에 따라 변하지 않는다
- 상단으로 페이드되는 글래스 배경 `backdrop-filter: blur(14px)`, **상단 테두리 없음**
- **탭 캡슐** — 4탭(홈 · 탐색 · 포트폴리오 · 내 정보), 높이 **58px**, 선택 탭만 진한 글씨 + 얕은 배경
- **AI 버튼** — 캡슐 오른쪽 **58px 원형**, `--t1` 배경. 누르면 채팅이 아래에서 올라온다
- 콘텐츠 하단 여백: 탭바 있는 화면 **132px**

#### Tab Bar 변형

| 상황          | 캡슐 내용                                                            |
| ------------- | -------------------------------------------------------------------- |
| 기본          | 4탭                                                                  |
| 종목 상세     | **매수 / 매도** 두 버튼으로 교체 (매수 `--up`, 매도 `--down` 테두리) |
| 거래정지 종목 | `거래정지` 한 줄, 비활성                                             |

- 교체는 좌→우 순차 등장 (420ms, 70ms 지연)
- AI 버튼 라벨은 화면에 따라 확장 — 기본은 아이콘만, 종목 상세에서 `이 종목 물어보기`
- **바텀시트가 열리면 탭바와 AI 버튼을 모두 숨긴다.** 시트가 단독 레이어가 된다

### Information Hierarchy

#### 종목 상세 기본 위계

`종목명·코드 → 현재가·등락 → 내 보유 Summary → 선택한 탭 콘텐츠 → 매수/매도`

탭 내부:

- 차트: 가격 흐름 → 평균 매수가 → 거래량 → 오늘 시세
- 기업: 기업 한 줄 요약 → 핵심 지표 → 매출/영업이익
- AI 분석: 한 줄 결론 → 확인할 위험 → 내 계좌 영향 → 투자 기준 → 일정

#### 일반 화면 기본 위계

1. 현재 상태
2. 사용자에게 중요한 변화
3. 분석 / 설명
4. 행동

## 7. Core Screens

### 7.1 홈

`지수 Horizontal Ticker → Compact AI 브리핑 → 총자산 → AI 수익 인사이트 → 내 종목 / 관심 종목`

#### 지수

- KOSPI / KOSDAQ / USD-KRW / NASDAQ
- **자동으로 흐르는 Animation은 사용하지 않는다**
- 한 줄 Horizontal Scroll
- 다음 항목 일부를 보여 스크롤 가능성을 자연스럽게 인지
- Scroll Snap 적용 가능
- 카드 / Pagination Dot / Arrow 없음
- 홈의 보조 정보로 낮은 시각적 강도 유지

#### AI 데일리 브리핑

- Compact Dark `AISummary`
- 한 줄 결론 + 핵심 Meta
- `확인 필요 N건`만 AI Accent 또는 Attention Text로 가볍게 강조
- Filled Badge / Pill 금지
- 전체 카드 클릭 + Chevron

#### 총자산

- Card로 감싸지 않고 Hero Information으로 배치
- `총자산 Label → 금액 → 오늘 손익 → 기준 시각`
- 손익금액과 수익률은 한 줄로 표시
- 수익률을 별도 Pill로 만들지 않는다

#### AI 수익 인사이트

- 총자산 바로 아래 `AIInline`
- 예: `오늘 내 자산은 왜 올랐을까요?`
- 한 줄 설명 + Chevron

#### 내 종목 / 관심 종목

- Text Tab
- Preview 2~3개 + 전체 보기
- Card보다 Flat List 우선
- 종목명 / 평가금액 Primary, 보조 정보 Secondary

### 7.2 탐색

`검색 → 최근 검색어 → 최근 본 종목`

#### 검색창

- 화면의 가장 중요한 인터랙션
- 종목명 또는 종목코드
- 1글자: `2글자 이상 입력해 주세요`
- 2글자 이상: 검색 결과 최대 10개
- 검색어는 `/search?q=`와 동기화

#### 최근 검색어

- Compact Chip
- 최대 10개
- 각 Chip에 `×`
- `전체 삭제` Secondary Action
- 많으면 Horizontal Scroll

#### 시장 랭킹은 넣지 않는다

**랭킹·추천 API를 만들지 않기로 확정했다** (2026-09-07). 이 절에 있던 급상승·급하락·전일 거래량 랭킹 명세를 걷어냈다.

근거는 셋이 같은 말을 한다 — `ia.md` 탐색 절에 랭킹 서술이 없고, `featureSpec` §12가 종목 순위를 확장 범위(MVP 이후)로 두었고, 이 문서 7.16 온보딩 절의 미확정도 "랭킹·추천 API는 만들지 않는다"로 적혀 있다. 이 절만 반대로 남아 있어 문서가 자기 안에서 모순이었다.

탐색 화면은 검색·최근 검색어·최근 본 종목으로 구성한다. 랭킹이 MVP로 다시 들어오면 이 절을 되살리고 `featureSpec` §12도 함께 고친다.

#### 최근 본 종목

- 하단 보조 Section
- 최대 3개 Preview + 전체 보기
- 종목명 / 종목코드 / 현재가 / 등락률
- 최근 본 API에 `market`이 없으면 시장명 표시 금지

#### 검색 상태

- 검색 중: 결과 영역 Skeleton/Loading
- 결과 없음: 간단한 Empty State
- 실패: 재시도
- 검색 결과 상태에서는 최근 기록을 숨기고 결과만 표시

#### 탐색 화면에서 제거

- 탭바 AI 버튼
- 알림함 아이콘 / 미확인 Badge

### 7.7 주문

#### 기본 구조

`종목 정보 → 수량 → 비율 버튼 → 주문 금액 / 주문 후 예수금 → AI 주문 전 점검 → 제출`

- 비율 버튼: `10% / 25% / 50% / 최대`
- 매수·매도 모두 동일한 기본 구조
- 최종 CTA가 화면에서 가장 강한 요소

#### 주문 전 AI 점검

**매수·매도 모두 제공한다.**

- `side = buy | sell`
- 주문을 가상 체결한 뒤 계좌 변화를 보여준다
- 승인 / 거절 / 추천 기능이 아니다
- 제출 버튼 바로 위에 위치

구성:

1. 핵심 변화 한 줄
2. 주문 전후 예수금
3. 주문 전후 포트폴리오 비중
4. 확인해볼 점
5. `참고용 정보예요.`

표현:

- `17% → 17%`처럼 동일값 반복 금지
- 변화 없음은 `17% · 큰 변화 없음`
- Before = Gray
- After / 핵심 결과 = White 또는 AI Accent
- Warning Triangle / Red Warning 금지

#### 체결 후 기록 범위

- **매수 체결 후:** 매수 이유 기록 흐름 O
- **매도 체결 후:** 이유 기록 흐름 X
- 매도 이유 / 손절 / 익절 / 분할 매도 기록은 MVP 범위 밖

### 7.12 나의 투자 기준

이 화면은 **Finch가 분석한 내 투자 생각을 확인하고 정리하는 곳**이다.

라우트는 **포트폴리오 탭 하나**(`/portfolio?tab=wiki`)로 통합한다. 독립 화면(`/my/wiki`)을 따로 두지 않는다. 진입점이 셋이어도 목적지는 하나다.

상단:

- `AIInline`
- 예: `Finch가 분석한 투자 기준이에요.`
- `대화와 투자 기록을 바탕으로 정리했어요.`
- `확정 1개 · 확인 필요 1개 · 매수 이유 1개`

세 영역:

#### 1. 확정된 투자 기준

- 이미 Finch가 참고 중
- Flat List
- 출처 + 날짜
- 삭제 기능은 `...`에 숨기지 않고 `삭제` Text Action으로 명확히 표시
- 삭제는 Secondary, Confirmation 단계에서만 Red

#### 2. Finch가 이렇게 이해했어요

추정이 여러 건 쌓일 수 있으므로 **한 번에 한 장씩 확인하는 Card Queue**로 구성한다.
목록으로 나열하면 화면이 길어지고 어느 것에 답해야 하는지 흐려진다.

- 흰 Surface Card + 얕은 Shadow, Radius 12px
- 카드 **아래쪽으로 두 겹이 7px · 13px씩 삐져나와** 뒤에 더 있음을 알린다. 2건 이상일 때만
- 카드 상단: AI Glyph + `확인이 필요해요` 라벨 + 우측 `‹ 1 / 3 ›` Navigator
- 카드 하단: **번호 버튼**(1 2 3). 현재 것만 Accent 채움, 눌러서 바로 이동
- `맞아요 / 아니에요` — 두 버튼 동일한 Compact Neutral Secondary Button
- Green / Red 금지
- 확인되면 확정된 기준으로 이동하고 큐에서 빠진다
- `아니에요`는 삭제가 아니라 **쓰지 않겠다는 확인**이다. 토스트도 그렇게 말한다
- 1건만 남으면 Navigator · 번호 · 쌓임을 모두 숨겨 단일 카드로 보인다
- 넘기기는 **버튼으로만** 한다. 드래그/스와이프는 쓰지 않는다 — 카드가 스크롤 영역 안에 있어 세로 스크롤과 충돌한다

#### 3. 종목별 매수 이유

- 종목명
- 매수 이유 원문
- 기록 시점 / 투자 기간
- 기존 기록이 있으면 `매수 이유 추가하기`
- 기록이 없으면 `매수 이유 기록하기`
- 펼친 뒤 `기록 수정하기`로 기존 원문을 고칠 수 있다. 기본은 Tertiary, Hover에서 Primary로 진해진다

##### 기록 시트의 두 모드

같은 시트가 신규·수정 두 모드를 가진다. 진입점마다 기록 유무를 확인해 모드를 정한다.

|        | 신규                      | 수정                                 |
| ------ | ------------------------- | ------------------------------------ |
| 제목   | `{종목}을 왜 담으셨나요?` | `{종목} 매수 이유`                   |
| 설명   | 기록을 권하는 문장        | `지금 생각이 달라졌다면 고쳐두세요.` |
| 입력   | 빈 상태                   | 기존 원문 Prefill                    |
| CTA    | `매수 이유 저장하기`      | `수정 저장하기`                      |
| 토스트 | `매수 이유를 기록했어요.` | `매수 이유를 수정했어요.`            |

- 수정 저장 시 **기록 시점과 투자 기간은 유지**한다
- 시트를 닫을 때 입력값·선택·모드를 모두 비운다. 진입점이 늘어도 이전 종목의 내용이 새지 않아야 한다

### 7.16 온보딩 — 관심 종목 선택

신규 사용자가 카카오 로그인 직후 만나는 첫 화면. **콜드 스타트를 푸는 자리**다.

가입 직후에는 보유·거래·기록이 모두 비어 있어 AI 기능 대부분이 열리지 않는다. 관심 종목 하나만 담으면 데일리 브리핑이 켜지므로, 온보딩의 첫 행동은 **매수가 아니라 관심 종목 담기**다. 돈을 넣기 전에 서비스의 값을 한 번 보여주는 구간이다.

#### 구조

세 층으로 고정한다. 종목 수가 늘어도 제목과 검색창이 화면 밖으로 밀리지 않는다.

| 층          | 내용                                          | 동작                        |
| ----------- | --------------------------------------------- | --------------------------- |
| 상단 (고정) | `건너뛰기` · 제목 · 설명 · 섹션 헤더 · 검색창 | 스크롤 안 함                |
| 중단        | 종목 리스트                                   | 내부 스크롤, 하단 32px 패딩 |
| 하단 (고정) | CTA                                           | 항상 같은 자리              |

- 브랜드 마크를 넣지 않는다 — 직전 랜딩에서 이미 봤다 (§3 반복 금지)
- 하단 탭바 없음
- 우측 상단 `건너뛰기` — Secondary Text Action

#### 카피

> 관심 있는 종목을
> 골라주세요
>
> 고른 종목을 기준으로 매일 필요한 소식을 모아드려요.

#### 종목 리스트

1열 컴팩트 row. 2열 그리드는 6자 한글 종목명이 잘려 쓰지 않는다.

- 썸네일 36px · 종목명 16px/600 · `종목코드 · 시장` 13px
- 세로 패딩 11px, 행 사이 얇은 구분선
- **가격·등락률을 보여주지 않는다** — 고르는 화면이므로 종목 식별만
- 카드 배경·테두리 없음

#### 선택 인디케이터

우측 22px 원형 체크박스.

| 상태   | 배경   | 체크 | 링          |
| ------ | ------ | ---- | ----------- |
| 미선택 | 투명   | 없음 | `--border2` |
| 선택   | `--t1` | 흰색 | `--t1`      |

- 선택 시 종목명이 굵어진다
- 행 전체가 클릭 영역
- 카드 반전·색 채우기 같은 큰 상태 변화는 쓰지 않는다

#### 카운터와 CTA

- 섹션 헤더 우측에 `0개 선택` / `2개 선택`
- CTA는 **최소 1개**부터 활성 — 미선택 시 `관심 종목을 선택해주세요`(비활성), 선택 후 `FINCH 시작하기`
- 최소 개수를 강제하지 않는다. 하나만 담아도 브리핑이 켜지므로 문턱을 올릴 이유가 없다

#### 더 많은 종목 · 검색

- 리스트 하단 `더 많은 종목 보기` Text Action → 전체 종목으로 확장, 버튼이 `접기 ⌃`로 바뀐다
- 섹션 제목도 `국내 주요 종목` → `전체 종목`
- 검색창은 **확장 상태에서만** 나타난다. 기존 검색 로직(종목명·종목코드 부분 일치) 재사용
- 검색 중에는 `더 많은 종목 보기`를 숨긴다
- 결과 없으면 안내 한 줄
- 거래정지 종목은 확장 목록에만 나오고 `거래정지` 라벨이 붙는다. 담는 것 자체는 막지 않는다

#### 완료 후 홈

- **관심 종목 탭이 기본으로 열린다** — 고른 종목이 소식 한 줄과 함께 보인다
- AI 브리핑이 켜진다 — "관심 종목에서 오늘 확인할 소식이 N건 있어요."
- `관심 종목을 담으면 소식을 모아드려요` 빈 카드는 자동으로 사라진다
- 총자산 0원은 남기되, 입금 CTA를 검정 버튼이 아니라 회색 액션 로우로 낮춘다 — 입금이 첫 행동처럼 보이지 않게

#### 건너뛴 경우

홈 상단에 관심 종목 유도 카드를 노출한다. 온보딩으로 되돌리지 않는다.

#### 미확정

**"국내 주요 종목" 5개의 선정 기준.** 현재는 종목 목록 앞 5개다. 실제로는 시가총액 상위 같은 기준이 필요하지만 해당 API가 없다. 랭킹·추천 API는 만들지 않는다.

## 8. AI Component System

AI 기능은 공통 UI 문법을 사용한다.
**화면마다 새 AI Card를 만들지 않는다.**

AI 슬롯은 **6종**이다 — 브리핑 · 종목 분석 · 주문 전 점검 · 포트폴리오 진단 · 수익률 원인 · 채팅. 인스턴스 수와 슬롯 종류를 혼동하지 않는다. `requestId 하나 = 피드백 슬롯 하나` 규약은 슬롯 종류 기준이다.

### 8.1 `AISummary`

정상 AI 결과의 Compact Summary.

구조:

1. 공통 AI Glyph + 기능 Label
2. 핵심 결론 최대 2줄
3. 핵심 Meta 최대 2개
4. 필요 시 Chevron

Style:

- Dark Surface (`--ai-surface` #24272C)
- Radius **12px**, Padding **18px**
- White Main Copy
- Gray Secondary
- AI Accent는 핵심 결과에만
- Divider X
- Bullet List X
- Full-width Button X
- Card 전체 Clickable
- Radius / Padding / Header 위치 통일

적용:

- 홈 AI 브리핑
- 포트폴리오 AI 진단
- 종목 AI 분석 요약
- 수익률 분석 요약
- 주문 전 점검

### 8.2 `AIInline`

기존 금융 정보에 붙는 짧은 AI Insight / Entry.

구조:

- 공통 AI Glyph
- Title
- Secondary Copy
- Chevron

Style:

- 큰 Dark Background 없음
- 기본 Background 또는 Light Surface
- 짧고 가볍게

적용:

- 홈 `오늘 내 자산은 왜 올랐을까요?`
- 마이페이지 `나의 투자 기준`
- `나의 투자 기준` 상단 Intro
- 기타 짧은 AI 진입점

### 8.3 `AIDetail`

상세 AI 분석 화면.

구조:
`결론 → 근거 → 위험/확인할 점 → 내 계좌 영향 → 일정/기준 → 출처 → Feedback`

Rules:

- 기본 Background 위 Flat Section
- 모든 Section을 Card로 만들지 않는다
- 상세 분석 전체를 하나의 Dark Card에 넣지 않는다
- Section 간 충분한 여백

### 8.4 Common AI Header

- AI Glyph 위치 / 크기 통일
- 기능 Label 예:
  - `AI 브리핑`
  - `AI 진단`
  - `AI 종목 분석`
  - `AI 수익 분석`
  - `AI 주문 전 점검`
- Label은 Small / Secondary
- Main Copy보다 강하지 않게

## 9. AI Evidence & Feedback

### 근거 표기

**뱃지를 쓰지 않는다.** 응답 블록 최하단에 캡션 한 줄로 종류만 나열한다.

```
08.28 09:00 기준 · 공시 · 뉴스 · 자체계산
```

- 위치: 응답 블록 최하단, Caption 크기
- 뱃지 · 링크 아이콘(↗) · 점선 테두리 · 개별 출처 링크를 쓰지 않는다
- 종류를 나열만 하고 개별 출처로 링크하지 않는다
- `AIDetail`에서도 같다. 상세 화면이라고 뱃지를 되살리지 않는다

과거 안(뱃지 7종 · 외부는 링크 · 내부는 점선)은 폐기했다. 모든 응답 블록에 뱃지가 반복되면서 화면마다 장식이 쌓였고, "AI 표시는 상단에서 한 번만"으로 정리했다.

### Feedback Rule

**requestId 하나 = Feedback Slot 하나**

- Section마다 붙이지 않는다
- 응답 블록 최하단에 하나
- `도움됐어요 / 아쉬워요`
- Compact Neutral Secondary Button
- Green / Red 사용 금지

#### 동작

- **`도움됐어요`** — 누르면 바로 전송
- **`아쉬워요`** — 사유 바텀시트를 연다

사유 바텀시트:

- 사유 칩 **6종 복수 선택** — 숫자가 틀렸어요 · 관련이 없어요 · 오래된 정보예요 · 너무 뻔해요 · 이해하기 어려워요 · 근거가 이상해요
- 자유 입력 한 줄 (선택)
- 하나라도 고르거나 적으면 `의견 보내기` 버튼이 나타난다
- 전송 후 슬롯은 `보냈습니다`로 바뀐다
- 슬롯 3곳(종목 상세 AI 탭 · 채팅 · 수익률 분석)이 같은 시트를 쓴다

**실패 / 데이터 부족 자리에는 Feedback을 노출하지 않는다.** 재시도가 유일한 주 동작이다.

### 표현 규칙

- `긍정 요인 / 부정 요인` 표현 금지
- 대신:
  - `시장이 주목하는 요인`
  - `확인해볼 위험`
  - `공시·실적에서 확인된 위험 요인`
- AI가 매수·매도를 단정적으로 지시하지 않는다

X `이 종목은 사지 않는 것이 좋습니다.`
O `반도체 비중이 48%예요. 한 업종이 흔들리면 계좌 전체도 함께 움직일 수 있어요.`

## 10. States

### Loading

- Skeleton 우선
- AI 응답은 `확인하고 있어요` + 절제된 점 모션
- Loading 때문에 전체 화면 구조가 크게 흔들리지 않게

### Empty

`데이터가 없습니다`를 쓰지 않는다.

예:

> 아직 관심 종목이 없어요.
> 관심 있는 종목을 담아보세요.

### AI 실패

재시도 가능한 오류.

재시도 가능한 코드는 화이트리스트로 관리한다. 모르는 코드는 재시도 불가로 취급한다.

| 재시도 | 코드                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 가능   | `RETRIEVAL_FAILED` · `LLM_TIMEOUT` · `AI_UPSTREAM_UNAVAILABLE` · `AI_UPSTREAM_TIMEOUT` |
| 불가   | `INSUFFICIENT_DATA` · `GUARDRAIL_BLOCKED` · 그 밖의 모르는 코드 전부                   |

UI:

- Dark AI Card 사용 금지 — 흰 면을 쓴다
- 기본 Background 위 Status UI
- Red Warning Box 금지

카피:

> 분석을 불러오지 못했어요.
> 잠시 후 다시 시도해 주세요.
> **[다시 시도]**

- Retry가 주 동작
- Feedback 노출 금지
- 채팅의 실패 상태도 같다. 검정 말풍선 안에 넣지 않는다

### AI 데이터 부족

오류가 아니라 아직 조건이 충족되지 않은 상태.

- Dark AI Card 사용 금지
- Retry 없음
- 해당 슬롯의 **실제 활성 조건**을 알려준다
- 모든 슬롯에 동일한 숫자 조건을 하드코딩하지 않는다

예:

> 아직 분석할 정보가 충분하지 않아요.
> 필요한 기록이 조금 더 쌓이면 분석 결과를 볼 수 있어요.

슬롯별 예:

- 수익률 원인 → 해당 기능의 실제 매매내역 조건
- 포트폴리오 진단 → 실제 보유 종목/업종 조건
- 종목 분석 → 필요한 공시/시세 데이터 조건

### 미기록 상태

경고가 아니다.

- 작은 Dot + 문장
- Warning Triangle / `!` / 큰 Red Badge / 빨간 배경 금지
- Dot은 Accent 또는 Notify
- 텍스트는 Secondary
- 기록 완료 즉시 제거
- `✓ 완료`를 계속 표시하지 않는다

## 13. Copy & Microcopy

### Tone

Finch는 다음처럼 말한다.

- 짧고 구체적
- `~해요 / ~했어요`
- 자연스러운 한국어
- 차분하지만 딱딱하지 않음
- 과하게 귀엽거나 감정적이지 않음
- 시스템/개발 용어를 사용자에게 노출하지 않음

### 피하는 표현

- 성공적으로
- 정상적으로
- 처리되었습니다
- 완료되었습니다
- 오류가 발생했습니다
- 데이터가 없습니다
- 해당
- 확인 바랍니다
- 유효하지 않습니다
- 진행하시겠습니까?

### Toast

결과가 중요하면 구체적인 숫자를 넣는다.

X `입금됐어요.`
O `1,000,000원을 입금했어요.`

X `관심종목에 추가되었습니다.`
O `관심 종목에 담았어요.`

X `삭제되었습니다.`
O `검색 기록에서 지웠어요.`

X `요청에 실패했습니다.`
O `잠시 문제가 생겼어요. 다시 시도해 주세요.`

### Confirmation

X `정말 삭제하시겠습니까?`

O

> 이 투자 기준을 삭제할까요?
> 삭제하면 Finch가 이후 분석에서 이 기준을 참고하지 않아요.

### Empty State

X `데이터가 없습니다.`

O

> 아직 최근에 본 종목이 없어요.
> 종목을 둘러보면 여기에 모아둘게요.

### AI Copy

보고서체를 피한다.

X `반도체 업종 집중도가 높은 상태입니다.`
O `반도체 비중이 83%로 한쪽에 많이 몰려 있어요.`

X `보조금 정책 개편에 따라 국내 판매 실적에 유의미한 영향이 발생할 수 있습니다.`
O `보조금 개편이 국내 판매에 영향을 줄 수 있어요.`

### CTA

기능 위치보다 **사용자가 무엇을 할 수 있는지**를 먼저 말한다.

X `알림함에서 기록하기`
O `매수 이유 기록하기`

X `AI 분석 보기`
O `수익이 난 이유 보기`

X `AI에게 질문하기`
O `이 종목 물어보기`

## 14. Do / Don't

### Do

- 중요한 숫자는 크게
- White / Graphite 중심
- AI 정상 결과는 Dark Summary로 명확히 구분
- AI 설명은 짧고 구조적으로
- 위험 요인을 근거와 함께 제공
- 보유 종목 / 관심 종목 / 투자 기록을 개인화 중심으로 사용
- 기록이 필요한 일은 알림함에 쌓아 두고 재촉하지 않기
- 같은 역할의 컴포넌트는 공통 UI로 재사용
- Section 내부는 Compact, Section 사이에는 충분한 여백

### Don't

- 제품 UI에서 상세 캐릭터 일러스트 반복
- 화면 전체 베이지 / 웜톤
- 흰 배경에서 AI Accent 남발
- 종목 로고에 진한 채도색 남발
- 모든 정보를 큰 카드로 감싸기
- 모든 버튼을 Pill로 만들기
- 전체 화면 Glassmorphism
- 과도한 Gradient / Shadow
- 상승·하락 색을 장식용·상태용으로 사용
- AI가 매수·매도를 단정적으로 지시
- 체결 직후 강제 모달로 기록 요구
- 매도 체결 후 매도 이유 기록 기능 임의 추가
- 모든 숫자를 한 화면에 노출
- AI Card마다 다른 아이콘 / Padding / Radius 사용
- 실패/데이터 부족을 정상 Dark AI Card 안에 표시
- 근거 뱃지 되살리기
- 검정 Surface 위에 `--t2` 같은 진한 회색 텍스트 사용

## 15. Final Direction

### Core Formula

> **White / Graphite = 신뢰감과 금융 정보**
> **Dark Surface = AI 정상 결과**
> **AI Glyph = AI가 관여한 순간의 공통 Signifier**
> **AI Accent = 검정 위 핵심 하나**

### Brand Formula

> **Finch는 귀여움을 전면에 내세우는 마스코트 앱이 아니라, 차분한 투자 UI 안에서 AI가 관여하는 순간을 명확하게 보여주는 서비스다.**

- 금융 데이터 화면에서는 브랜드 일러스트를 반복하지 않는다
- 제품 UI의 AI 표현은 공통 AI Glyph와 Component로 통일
- 한 화면에서 AI를 과도하게 반복하지 않는다

### Visual Direction

- **Base:** White & Graphite
- **AI Summary:** `--ai-surface` #24272C + White
- **AI Accent:** `#E9C77F`, Dark Surface 한정
- **Notification:** `--notify` #D94A4A Small Dot
- **Type:** Pretendard + tabular-nums
- **Shape:** 카드 **12px** Radius
- **Structure:** Card 남발보다 Typography / Spacing / Alignment
- **Effects:** Shadow 최소화
- **Interaction:** 필요한 순간에만 Motion

### Product Goal

**목표는 "귀여운 투자 앱"이 아니다.**

> **신뢰할 수 있고, 정보가 많아도 빠르게 읽히며,
> AI를 만나는 순간이 일관되고 분명한 투자 앱.**
