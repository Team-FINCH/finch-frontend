# 프로토타입 ↔ 구현 대조 — 마이페이지 (`/my` ↔ `isMy`)

- 작성: 2026-09-09 / 기준 커밋 `fa5850d` (master)
- **1차 `prototype-diff.md` 와 같은 형식이다.** 표 칸 · 근거 표기 · 화면 경계 기준 · 상태 분기를 세는 법이 모두 같다. 새 형식을 만들지 않았다
- **판정 규칙은 [`prototype-diff.md` 의 "판정 규칙" 절](./prototype-diff.md)에 있다.** 여기서 다시 적지 않는다
- **`판정` 칸은 비어 있다. 사용자가 채운다.** `(잠정) 의견` 은 워커의 한 줄 소견이고 결정이 아니다
- `proto L####` 는 디코드본 기준 줄 번호다(4,164줄). `app-logic.js` 의 줄 번호 `N` 은 디코드본 `L(N+3033)` 이다

## 화면 경계 — 라우트와 블록 이름을 먼저 맞춘다

| 우리 라우트 | 우리 파일    | 프로토타입 블록 | 디코드본 범위 |
| ----------- | ------------ | --------------- | ------------- |
| `/my`       | `MyPage.tsx` | `isMy`          | L2532–L2576   |

**라우트는 `/mypage` 가 아니라 `/my` 다**(`routes.ts:87`). **프로토타입 블록 이름도 `isMypage` 가 아니라 `isMy` 다** — 화면 전환 값만 `s.screen==="mypage"` 다(app-logic.js:403 → L3436). 1차 문서 부록의 `내 정보` 2건이 이 블록(#29, L2533)과 공통 탭바(#30, L2868)를 가리킨다.

우리 쪽 구성 파일 — `pages/MyPage.tsx`(배치) · `features/mypage/components/MyPageProfile.tsx` · `MyPageMenu.tsx` · `features/auth` 의 `LogoutButton.tsx`.

## 상태 분기를 어떻게 셌나

`isMy` 블록의 `sc-if` 는 **하나뿐이다**(알림 뱃지 `hasMail`, L2533). 네 탭 중 가장 단순하다.

| 묶음      | 조건 태그         | 갈래             |
| --------- | ----------------- | ---------------- |
| 알림 뱃지 | `hasMail` (L2533) | 미읽음 있음/없음 |

시연용 세그먼트 셋(`계정 상태` · `예외 상태` · `AI 상태`, L2551–L2573)은 `sc-if` 가 아니라 클래스 바인딩(`{{ dataSegFull }}` 등)으로 선택 상태만 바꾼다 — 갈래로 세지 않았다.

**로딩·실패 상태는 프로토타입에 없다.** 우리 구현은 `GET /users/me`·`GET /deposits/limit` 두 쿼리가 있어 갈래가 넷 더 있다.

## 프로토타입 ↔ `design.md` 어긋남

**고치지 않았다.** 두 근거가 서로 다른 말을 하는 자리만 모았다.

1. **`투자 계좌는 Light Surface`** — `design.md` L796 이 별도 면을 요구하지만 프로토타입 `isMy` 의 투자 계좌 행은 다른 행과 같은 `.row` 흰 배경이다(L2540). 우리 구현도 면이 없다
2. **`AI 상태(시연용)`** — `design.md` L790 이 구조 6번, L799 가 "최하단 별도 Demo Section" 으로 정식 항목처럼 적었다. 그런데 프로토타입은 그 블록 위에 **`실제 서비스에는 없는 화면입니다`** 를 직접 적어 두었다(L2567). design.md 가 프로토타입의 자기 부인을 그대로 명세로 옮긴 것으로 보인다
3. **로그아웃의 모양** — `design.md` L800 "Secondary Text Action" 과 프로토타입 `.b1 mu` 텍스트가 같은 말을 하고 **우리 구현만 54px 버튼이다.** 두 근거가 일치하는데 구현이 어긋난 자리다
4. **`design.md` 가 아직 옛 용어를 쓴다** — §7.14 제목이 `내 정보` 고 구조 4번이 `충전` 이다(L781, L788). MR !148 이 화면 용어를 `마이페이지`·`입금` 으로 통일했는데 `design.md` 는 갱신되지 않았다. **프로토타입만이 아니라 레포 문서도 옛 용어다** — 아래 용어 절을 본다
5. **탭 라벨** — `design.md` L253·L263 이 탭 이름을 `내 정보` 로 적었다. 프로토타입 탭바(L2868)도 같고 우리 구현만 `마이페이지` 다(`routes.ts:116`). 탭바 문서에 같은 행이 있다
