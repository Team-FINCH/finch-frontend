## 이번 범위 — 탭바만

탭바는 화면이 아니라 4탭이 공유하는 공통 요소다. 디코드본에서 `is404` 뒤쪽(`__GLOBAL_after_404__`, **L2897–L3074**)에 FAB · 탭바 · 바텀시트 8종이 함께 들어 있고, 이번 묶음에서는 **탭바만** 다룬다.

| --------------------- | ----------------- | ------------------------------------ | ------------ |

**다루지 않는 것** — `.fab`(브리핑 전용, L2897–L2901)과 매수/매도 변형(`.tabpill.trade`, L2913–L2926)은 이번 범위(4탭) 밖이라 표에서 뺐다. `.fab` 는 브리핑 화면, `.trade` 는 종목 상세 묶음에서 다룰 자리다. 다만 두 변형이 같은 셸을 쓰기 때문에 A 절의 셸 항목은 셋에 공통으로 걸린다. 바텀시트 8종(L2933–L3074)은 다음 묶음이다.

## 상태 분기를 어떻게 셌나

`__GLOBAL_after_404__` 안에서 탭바에 걸리는 `sc-if` 는 다섯이다.

| 조건 태그   | 위치  | 갈래                                                               |
| ----------- | ----- | ------------------------------------------------------------------ |
| `showFab`   | L2897 | 브리핑 화면에만 `.fab` (**이번 범위 밖**)                          |
| `showTabs`  | L2903 | 탭바 자체를 그릴지 — 시트가 열려 있거나 5화면 밖이면 안 그린다     |
| `tabNav`    | L2905 | 4탭 캡슐 (종목 상세가 아닐 때)                                     |
| `tabTrade`  | L2913 | 매수/매도 캡슐 (종목 상세, **이번 범위 밖**)                       |
| `showTabAi` | L2927 | AI 버튼 — **재내보내기 뒤에는 `true` 고정이라 모든 화면에 그린다** |

`showTabs`·`tabNav`·`showTabAi` 세 조건의 실제 값은 디코드본 L3455–L3457 에 있다.

```
showTabs: !s.sheet && ["home","search","portfolio","mypage","detail"].includes(s.screen),
tabNav: s.screen!=="detail", tabTrade: s.screen==="detail",
showTabAi: true,
```

**`showTabAi` 가 재내보내기에서 바뀌었다.** 옛 디코드본(`fa5850d`)은 `s.screen!=="search"` 라서 탐색만 AI 버튼을 뺐는데, 새 디코드본은 `true` 고정이다. 숨김 규칙은 AI 진입점이 플로팅이던 시절의 것이고 탭바 안으로 들어간 뒤에는 셸이 화면마다 달라지는 문제가 된다 — `design.md` v2.5 Appendix 7번이 그렇게 정리했다.

**그래도 `showTabs` 와 `showTabAi` 는 별개 플래그다.** 셸을 그릴지와 그 줄 끝에 AI 버튼을 놓을지가 따로 계산된다. 지금 두 값이 같은 결과를 내는 것은 우연이 아니라 결정이고, 다시 갈릴 수 있으니 판정 자리는 셸 한 곳에 남겨 둔다.

## 일치 확인한 항목

표에 이미 넣은 것 말고, 따로 확인해 어긋나지 않은 것들이다.

- 탭 4개와 그 순서 (홈 · 탐색 · 포트폴리오 · 4번째)
- `.tabbar` 실측값 전부 (98px 고정 · `gap:10px` · `padding:0 16px 16px` · 상단 테두리 없음)
- 글래스 배경의 그라디언트 · 블러 14px · 페이드 마스크 58%
- `.tabpill` 실측값 전부 (58px · `padding:5px` · `rgba(255,255,255,.72)` · 테두리 알파 .07 · 블러 18px saturate 1.6 · 그림자)
- 탭 버튼 48px · 반경 999px · 아이콘 간격 8px · 글자 14px/500
- 선택 탭의 `flex:2.2` 와 `#EEF1F5` 배경
- 비선택 탭은 아이콘만, 선택 탭만 라벨을 펼치는 방식
- 탭 아이콘 네 SVG 의 경로 데이터
- 아이콘 색을 `currentColor` 로 두는 방식
- 순차 등장 420ms 와 50 / 100 / 150ms 지연

- AI 버튼을 놓을지의 판정을 셸 한 곳에 둔 구조 (탐색에서 숨기는 처리 자체는 재내보내기에서 없어졌다)

- AI 버튼 기본 라벨 `AI에게 묻기`

## 프로토타입 ↔ `design.md`·`ia.md` 어긋남

**고치지 않았다.** 두 근거가 서로 다른 말을 하는 자리만 모았다.

1. **4번째 탭 라벨** — **프로토타입은 재내보내기에서 `마이페이지` 로 고쳐졌다**(L2910). 남은 것은 `design.md` L253·L263 과 `ia.md` L339 로, 둘 다 아직 `내 정보` 다. **우리 레포 문서라 고칠 자리다** — 이 묶음 밖이라 손대지 않았다
2. **본문 하단 여백** — `design.md` L255 는 132px, 프로토타입은 `.sc` 28px + 탭바 98px = 126px, 우리 구현은 탭바 98px + safe-area + `PageMain` 24px 이다. 세 값이 다르고 어느 것이 기준인지 정해져 있지 않다. 홈·탐색·포트폴리오 문서에도 같은 행이 있다
3. **탭 바 변형 표의 `거래정지` 라벨** — `design.md` L275 는 `거래정지` 한 줄, 프로토타입은 `거래정지된 종목이에요`(L2923)다. 우리 구현은 `거래정지 · 주문 불가`(`TabBar.tsx:288`)로 **셋 다 다르다.** 이번 범위(4탭) 밖이라 표에 넣지 않았고 종목 상세 묶음에서 다룰 자리다
4. **AI 버튼이 탭바 안인가 밖인가** — 이 어긋남은 정리됐다. `design.md` L249 가 "AI 진입점은 플로팅이 아니라 탭바 안에 있다" 로 프로토타입 쪽으로 확정됐다.
5. **탐색 화면의 AI 버튼** — `design.md` §6 "Tab Bar > 적용 범위" 표(L263)와 L395 가 아직 "(탐색은 숨김)" 이라고 적는다. 프로토타입은 `showTabAi: true`(L3457) 로 바뀌었고 `design.md` v2.5 Appendix 7번이 노출 쪽으로 정리했다 — **표 두 자리가 Appendix 와 서로 어긋난다. 우리 레포 문서라 고칠 자리다**
