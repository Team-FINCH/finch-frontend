# 프로토타입 ↔ 구현 대조 — AI 채팅 (`/chat` ↔ `isChat`)

- 작성: 2026-09-09 / 기준 커밋 **master `2febe11`**
- **1차 `prototype-diff.md`·2차와 같은 형식이다.** 표 칸 · 근거 표기 · 화면 경계 기준 · 상태 분기를 세는 법이 모두 같다. 새 형식을 만들지 않았다
- **판정 규칙은 [`prototype-diff.md` 의 "판정 규칙" 절](./prototype-diff.md)에 있다.** 여기서 다시 적지 않는다
- **`판정` 칸은 비어 있다. 사용자가 채운다.** `(잠정) 의견` 은 워커의 한 줄 소견이고 결정이 아니다
- `proto L####` 는 디코드본 기준 줄 번호다(4,164줄). `app-logic.js` 의 줄 번호 `N` 은 디코드본 `L(N+3033)` 이다

프로토타입은 `msgs`·`draft`·`chatCtx`(종목명 문자열)·`chatLoading`·`chatFailed` 를 화면 상태로 갖고(app-logic.js:128 → L3161) 응답을 900ms 뒤 목으로 만든다(`ask`, app-logic.js:321-335 → L3354–L3368). 우리는 `POST /ai/chat` 단발 요청이고(SSE 폐기, C4) 맥락은 `?screen=`·`?ticker=` 쿼리로 받아 첫 메시지에만 싣는다.

**피드백 사유 시트(`sheetFbReason`)는 이 화면에서 열려야 하지만 여기서 세지 않는다.** [`prototype-diff-sheets.md`](./prototype-diff-sheets.md) E 절이다. 이 문서에는 "여는 자리가 있는가" 만 넣었다.

## 상태 분기를 어떻게 셌나

`isChat` 안의 `sc-if` 는 열이고, 그 밖에 진입·퇴장 모션 클래스 `riseCls` 가 있다.

## 일치 확인한 항목

표에 이미 넣은 것 말고, 따로 확인해 어긋나지 않은 것들이다.

- 라우트 `/chat` 이 `ia.md` §1 과 `routes.ts:76` 에서 같다. 탭바 밖 라우트인 것도 같다
- 채팅 화면에 탭바·FAB 를 두지 않음
- 초기화 버튼을 메시지가 있을 때만 보이는 조건
- 사용자 말풍선 최대 폭 80%
- AI 말풍선 모서리 `6px 18px 18px 18px`
- 피드백 버튼 문구 `도움됐어요`·`아쉬워요` 와 "답변 말풍선마다 하나" 단위
- 실패 상태를 검정 말풍선 안에 넣지 않음
- 실패 시 사용자 메시지가 목록에 남음
- 전송 뒤 입력창 비우기
- 요청이 단발(SSE 아님)인 것 — 프로토타입 목도 한 번의 응답이다

## 프로토타입 ↔ `design.md` 어긋남

**고치지 않았다.** 두 근거가 서로 다른 말을 하는 자리만 모았다.

1. **빈 상태 인사 문장** — design.md L815 는 `내 투자 맥락을 아는 Finch AI와 이야기해보세요.`(한 문장, `Finch`, 마침표), 프로토타입 L2460 은 `내 투자 맥락을 아는<br>FINCH AI와 이야기해보세요`(두 줄, `FINCH`, 마침표 없음). 네비 제목도 프로토타입은 `FINCH AI` 다. 브랜드 표기(`FINCH`/`Finch`)가 두 문서에서 갈린다 — 위키 탭 문서(2차 "어긋남" 7번)와 같은 계열
2. **피드백 전송 뒤 문구** — 프로토타입 `보냈어요`(L2502), design.md L1174 `보냈습니다`. 종목 상세 AI 탭(L1960)도 `보냈어요` 라 프로토타입 안에서는 일관된다
3. **가드레일 카피의 출처** — design.md L1276-1277 카피가 프로토타입 L3340-L3341 과 글자까지 같다. 어긋남이 아니라 **일치**인데 여기 적는 이유는 우리 구현이 서버 `message` 를 쓰기로 해서(컨벤션 §5) 이 카피가 프론트 어디에도 없기 때문이다 — 서버가 다른 문장을 보내면 두 문서 모두와 어긋난다
4. **근거 캡션의 출처 목록** — 프로토타입 L2496 `출처 시세 · 뉴스 · 내 기록`, design.md L1144 예시 `공시 · 뉴스 · 자체계산`. 예시라 어긋남으로 세지 않지만, 채팅은 `toolsUsed` 배열(`chat.ts:68`)이 있어 출처를 만들 재료가 응답에 있다
