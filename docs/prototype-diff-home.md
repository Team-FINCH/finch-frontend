## 일치 확인한 항목

표에 이미 넣은 것 말고, 따로 확인해 어긋나지 않은 것들이다.

- 라우트 `/`(`ROUTES.home`)가 `ia.md` L65 와 `shared/config/routes.ts:38` 에서 같다
- 블록 순서 — 브리핑 → 총자산 → 내 종목/관심 종목 (프로토타입 · `design.md` L306 · `HomePage.tsx:61-72` 셋이 같다. 지수·AI 인사이트 두 자리만 비어 있다)
- 브리핑 실패 자리에 피드백을 붙이지 않음
- 총자산을 카드로 감싸지 않음
- 총자산 0원 상태에서 손익·기준 시각을 그리지 않음
- 0원 상태 CTA 를 검정 버튼이 아니라 회색 액션 로우로 둠
- 알림함 봉투 아이콘 SVG 경로와 뱃지 치수
- 내 종목 행의 `.row`·`.th` 실측 치수 (72px · 44×44 · 반경 14px · 간격 12px)
- 내 종목 오른쪽 숫자 두 줄 구성 (평가금액 + 수익률, 평가손익 금액 없음)
- 내 종목 빈 상태 두 문장
- 관심 종목 빈 상태 CTA 문구 `종목 찾아보기`
- 탭 기본값이 내 종목이고 온보딩 뒤에는 관심 종목
- 홈에 토스트가 없음

## 프로토타입 ↔ `design.md` 어긋남

**고치지 않았다.** 판정 대상이 아니라 두 근거가 서로 다른 말을 하는 자리라서 여기 모았다.

1. **지수 티커** — `design.md` L308–L316 은 지수 4종을 요구하면서 L311 에서 "**자동으로 흐르는 Animation은 사용하지 않는다**", L312 에서 "한 줄 Horizontal Scroll" 이라고 못박았다. 그런데 프로토타입 `.mkroll` 은 `animation: mkroll 12s ... infinite` 로 **세로 자동 롤링**이다(proto L1200). 지수 API 자체가 없어(`ia.md` L65) 지금은 양쪽 다 만들지 않았지만, 되살릴 때 어느 쪽 모양인지가 정해져 있지 않다
2. **`확인 필요 N건` 강조** — `design.md` L322 는 이 문구만 AI Accent 로 가볍게 강조하라고 적었다. 프로토타입의 `briefMetaLine` 은 그 문구를 캡션 회색 한 줄에 그냥 섞어 넣고 강조하지 않는다(proto L1390, app-logic.js:494). 우리 구현에는 문구 자체가 없다 — **세 근거가 셋 다 다르다**
3. **AI 수익 인사이트(`AIInline`)** — `design.md` L333–L337 이 총자산 바로 아래 한 줄 블록을 요구하지만 프로토타입 `isHome` 마크업에 대응물이 없다. `HomePage.tsx:27-31` 이 이미 같은 것을 적어 두었고 `ia.md` §4 표와도 갈린다
4. **탭바 있는 화면의 하단 여백** — `design.md` L255 는 132px 을 요구한다. 프로토타입은 `.sc` 의 28px + `.tabbar` 98px 이고, 우리 구현은 `PageMain` 24px + `TabBarLayout` 98px + safe-area 다. 세 값이 다 다르다
5. **관심 종목의 `보유` 표시** — `design.md` L346 은 뱃지, 프로토타입은 표시 자체가 없고, 우리는 보조 줄 텍스트다
6. **관심 종목 빈 상태 문구의 출처** — 우리 문구(`눈여겨보는 종목을 담아보세요.`)는 프로토타입의 **죽은 블록**(탐색 화면 `showWatch`, 고정 `false` — `ia.md` L138 이 이미 지적했다)에서 온 것이고 살아 있는 홈 블록의 문장이 아니다
