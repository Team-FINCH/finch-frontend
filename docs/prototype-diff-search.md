- 작성: 2026-09-09 / 기준 커밋 `fa5850d` (master)
- **1차 `prototype-diff.md` 와 같은 형식이다.** 표 칸 · 근거 표기 · 화면 경계 기준 · 상태 분기를 세는 법이 모두 같다. 새 형식을 만들지 않았다

- `proto L####` 는 디코드본 기준 줄 번호다(4,164줄). `app-logic.js` 의 줄 번호 `N` 은 디코드본 `L(N+3033)` 이다

## 상태 분기를 어떻게 셌나

`isSearch` 블록의 최상위 `sc-if` 는 여섯이고 중첩까지 열이다.

| 묶음         | 조건 태그                                                                                                               | 갈래                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |

| 관심 종목 탭 | `showWatch` (L1664) · `watchEmpty` (L1665) · `w.suspended` (L1678) · `w.hasHint` (L1680)                                | **전부 죽은 갈래** — 아래 F 절을 본다 |

**로딩·실패 상태는 검색 결과에만 있다.** 최근 검색어·최근 본 종목에는 프로토타입에도 우리 구현에도 로딩·실패 갈래가 없다.

## 프로토타입 ↔ `design.md` 어긋남

**고치지 않았다.** 두 근거가 서로 다른 말을 하는 자리만 모았다.

1. **검색 결과의 거래정지 표시** — 프로토타입이 자기 안에서 갈린다. 홈·관심 목록은 `.tag u` 캡슐 뱃지(L1477)이고 검색 결과는 캡슐 없이 11px/600 적색 글자(L1605)다. `design.md` 는 §7.3·`ia.md` L134 에서 "검색 결과 행에도 같은 뱃지를 쓴다" 고 적어 캡슐 쪽을 말한다
2. **최근 본 종목의 `전체 삭제`** — `design.md` L384 는 "각 행에 `×`(개별 삭제)와 `전체 삭제`를 함께 둔다. 최근 검색어와 같은 규칙이다" 라고 적었다. 프로토타입은 행별 `✕` 만 두고 `전체 삭제` 는 두지 않았다(L1640–L1642). API(`DELETE /stocks/recent`)는 있다(`ia.md` L127)
