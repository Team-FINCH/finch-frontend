- **1차 `prototype-diff.md` 와 같은 형식이다.** 표 칸 · 근거 표기 · 화면 경계 기준 · 상태 분기를 세는 법이 모두 같다. 새 형식을 만들지 않았다

- **`판정` 칸을 채웠다** (2026-09-09, 판정 규칙 적용). `(잠정) 의견` 은 대조 워커의 한 줄 소견이고 결정이 아니다 — 규칙과 어긋나는 자리는 규칙을 따랐다
- **`proto L####` 는 새 디코드본 기준 줄 번호다(4,269줄).** 2026-09-09 에 프로토타입 재내보내기(`99c6c71`)를 반영해 옛 디코드본(4,165줄) 번호에서 갱신했다. 탐색 블록은 `L1565–L1693` 으로 한 줄씩 밀렸다

- 1회차에 `shared/` 경계 밖이라 넘겼던 행(검색 입력 스크롤 고정 · 거래정지 뱃지 면색 · 하단 여백 · 탭바 AI 버튼)은 FINCH-209 가 공용 코드를 세운 뒤 3회차에 풀렸다

## 상태 분기를 어떻게 셌나

`isSearch` 블록의 최상위 `sc-if` 는 여섯이고 중첩까지 열이다.

| 묶음         | 조건 태그                                                                                                               | 갈래                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |

| 관심 종목 탭 | `showWatch` (L1665) · `watchEmpty` (L1666) · `w.suspended` (L1679) · `w.hasHint` (L1681)                                | **전부 죽은 갈래** — 아래 F 절을 본다 |

**`showWatch` 는 `false` 로 하드코딩돼 있다**(proto L3620). 그래서 L1665–L1691 의 관심 종목 목록은 프로토타입에서 한 번도 그려지지 않는다. `ia.md` L138 이 이미 이 사실을 적었고 이 문서도 근거로 쓰지 않는다 — 다만 "센 것"으로 남기려고 F 절에 따로 뒀다.

**로딩·실패 상태는 검색 결과에만 있다.** 최근 검색어·최근 본 종목에는 프로토타입에도 우리 구현에도 로딩·실패 갈래가 없다.

## 프로토타입 ↔ `design.md` 어긋남

**고치지 않았다.** 두 근거가 서로 다른 말을 하는 자리만 모았다.

1. **검색 결과의 거래정지 표시 — 해소됐다.** 옛 디코드는 프로토타입 자기 안에서 갈렸다(홈·관심 목록은 `.tag u` 캡슐, 검색 결과는 캡슐 없는 11px/600 적색 글자). 재내보내기(`99c6c71`)가 여섯 자리를 모두 `.tag ne`(중립 캡슐, `L1117`)로 통일했다 — 검색 결과는 `L1606` 이다. `design.md` §7.3·`ia.md` L134 와도 같은 말이 됐다. 면 토큰 차이도 없어졌다 — `StockRow` 의 `SuspendedBadge` 가 `bg-surface-soft`(`#F1F3F6`)를 쓴다. 토큰 파일 주석이 `primary-soft` 를 "선택된" 상태 전용으로 못박은 것과 맞는다
2. **최근 본 종목의 `전체 삭제`** — `design.md` L384 는 "각 행에 `×`(개별 삭제)와 `전체 삭제`를 함께 둔다. 최근 검색어와 같은 규칙이다" 라고 적었다. 프로토타입은 행별 `✕` 만 두고 `전체 삭제` 는 두지 않았다(L1641–L1643). API(`DELETE /stocks/recent`)는 있다(`ia.md` L127)
3. **탭바 AI 버튼 — 답이 뒤집혔다.** 옛 프로토타입은 `showTabAi: s.screen!=="search"` 로 탐색에서 숨겼고 `design.md` L263·L395 도 숨김을 적었다. 재내보내기가 이것을 `showTabAi: true`(L3457)로 바꿨고 `design.md` v2.5 Appendix 7번이 "탐색에서도 노출" 로 정정했다. **우리 구현도 더는 숨기지 않는다** — `shared/ui/TabBar.tsx` 의 `showsTabAiButton` 은 없어졌고 `TabBarShell` 이 화면을 가리지 않는다. 남은 것은 `design.md` L263·L395 두 자리뿐이다
4. **하단 여백 132px** — 홈 문서의 같은 항목과 같다
5. **결과 개수 상한 10개** — `design.md` L359 가 "검색 결과 최대 10개" 라고 적었지만 프로토타입과 우리 구현 어느 쪽도 화면에서 자르지 않는다. 서버 기본값이 10인지가 근거로 확인되지 않았다
