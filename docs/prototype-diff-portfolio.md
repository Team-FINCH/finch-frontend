## 재내보내기가 답을 바꾼 행 · 옛 문서가 틀린 행

**새 디코드본(master `87c63d9`)에서 같은 항목을 다시 찾아 확인한 결과다.** 프로토타입 재내보내기(커밋 `99c6c71`, 449줄 변경)가 답을 바꾼 행과, 옛 문서가 사실을 잘못 적은 행을 여기 모았다. 위 표의 해당 칸은 이미 고쳤다.

### 재내보내기가 바꾼 것

1. **예수금 줄의 진입 버튼 문구** — `충전하기` → `입금하기`(L2170). 이슈 #45 의 용어 통일 요청이 받아들여졌다. 아래 "용어" 절의 판정이 `완료` 로 바뀐 근거다
2. **종목별 매수 이유 행이 1단에서 2단이 됐다**(L2449-2454). 이름이 위, `{날짜} 기록 · {기간}` 이 아래로 내려갔고 이름에 말줄임이 붙었다. 보유하지 않는 종목이면 메타에 `보유하지 않는 종목 · ` 접두가 붙는다(L4182) — 우리 `(비활성)` 과는 다른 축이라(보유 여부 ↔ 논지 `status`) 우리 표시는 그대로 두고 배치만 맞췄다
3. **빈 상태 설명의 최대 폭** — `.est>p` 가 250px → 270px 이고 `word-break:keep-all` 이 붙었다(L1215)
4. **차트 세그먼트가 4개(`1개월 / 3개월 / 1년 / 3년`)로 늘었다**(L1764-1767). 포트폴리오 4탭에는 대응 행이 없어 이 문서의 판정에는 들어오지 않는다. 우리는 봉 종류를 유지하기로 결정했고(이슈 #37 · `apiSpec` §5.3 v0.8.4) 디자인에 문서 정정을 요청해 둔 상태다

### 옛 문서가 잘못 적은 것

1. **"삭제 확인 단계 — 프로토타입: 없다"** — 프로토타입도 `delfact` 시트를 연다(L4165). 옛 디코드에도 같은 코드가 있어 재내보내기와 무관한 오독이다. 판정은 그대로 `완료` 지만 근거가 뒤집혔다
2. **"미기록 종목 보조 줄 — 프로토타입: `{종목코드} · {시장}`"** — `unrecorded` 의 `sub` 는 `{수량}주 · {평단}원` 이다(L4173). 옛 문서가 근거로 든 `L3292` 는 종목 목록 행(`stockRow`)의 `sub` 로 다른 객체다. 우리 구현과 일치한다
3. **"여러 개 동시 펼침 — `t.open` 이 항목별이라 여러 개가 열릴 수 있는 구조"** — `thesisOpen` 은 종목 코드 하나를 담고 같은 것을 다시 누르면 `null` 이 된다(L4184-4185). 한 번에 하나만 열린다 — 우리와 같다
4. **"하단 여백 — `.sc` 의 28px + 탭바 98px"** — 탭 화면에서는 `.hastab .sc` 가 `padding-bottom:132px` 로 덮는다(L1044). 프로토타입과 `design.md` L255 가 132px 로 같다
